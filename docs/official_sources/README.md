# Sources officielles

Les sous-dossiers classent les documents par organisation ou domaine. Ils sont
vides tant qu'aucun document identifiable n'a été importé. Un fichier présent
ici n'est pas automatiquement officiel : sa fiche d'identité et son contrôle
restent obligatoires.

Catégories disponibles : DEA, AFGSU, HAS, ANSM, SAMU, SMUR, SFMU,
Ministère_Santé, Code_Santé_Publique, Urgences, Anatomie, Physiologie,
Pathologies, Pharmacologie, Hygiène, Infectiologie, Transport_Sanitaire,
Communication, Psychologie, Pédiatrie, Gériatrie, Obstétrique, Traumatologie,
Cardiologie, Neurologie, Pneumologie, Endocrinologie, Dermatologie,
Toxicologie, Radiologie et Réanimation.
